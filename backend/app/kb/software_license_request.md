# Software License & SaaS Tool Request Policy

## Approved Core Software Stack
Every employee is provisioned core enterprise tooling upon onboarding:
- Google Workspace (Gmail, Drive, Docs, Meet)
- Slack Enterprise Grid
- 1Password Team Vault
- Notion for internal documentation

## Requesting Specialized Software
If you require specialized licenses (e.g., JetBrains All Products Pack, GitHub Copilot, Figma Professional, AWS Console IAM Access, Docker Desktop Pro):
1. Verify if an existing team license seat is available by checking the `#it-licenses` Slack channel.
2. Submit a QuickDesk ticket under category 'IT' with title format: `[Software Request] <Tool Name> - <Team Name>`.
3. Include your GitHub/email handle and cost center code.
4. Tier-1 developer tools (under $50/month) require direct manager sign-off. High-tier software (above $1,000/year) requires VP approval. Provisioning takes 24 to 48 hours.
